# Cup Legend portraits

Drop a real photo here to replace the faceless silhouette pictogram on each
Cup Legend's card and hero banner. Expected filenames (see `lib/cupLegends.ts`
for the exact paths):

- `larsson.jpg` — Henrik Larsson (Larsson Cup)
- `dalglish.jpg` — Kenny Dalglish (Dalglish Cup)
- `maradona.jpg` — Diego Maradona (Maradona Cup)
- `pele.jpg` — Pelé (Pele Cup)

No file needed for the app to work — `LegendPortrait` automatically falls
back to the silhouette if the image 404s, so this folder can stay empty.
